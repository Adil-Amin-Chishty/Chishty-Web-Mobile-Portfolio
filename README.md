# Chishty Productions | Web & Mobile Development

A responsive development portfolio with a Three.js laptop/phone scene and a scroll-driven, perspective project journey.

[Live portfolio](https://adilchisty963.systeme.io/20e78cb8)

## Run and Build

Open `index.html` in a browser. To regenerate the standalone page and Systeme.io integrations, run:

```sh
node build.mjs
```

No package installation is needed. Three.js and Lucide load from pinned CDN URLs; Google Fonts provides the typography. Source files are `body.html`, `style.css`, and `app.js`. All build assets and the original Chishty Productions logo are included in `assets/`.

## Features

- Scroll-driven project depth transitions and numbered navigation.
- Real project screenshots, category filters, detail dialogs, and source/demo links.
- Interactive 3D models, flowing water, rotation/reset/pause controls.
- Responsive layouts, keyboard controls, and a static grid for reduced-motion visitors.

## Systeme.io

`systeme-footer.html` is the published footer integration. Select all existing code in the footer editor before replacing it. `systeme-embed.html` provides an inline alternative. The standalone contact actions open an email draft; no visitor data is stored by this code.
